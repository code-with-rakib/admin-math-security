# Admin Math Security

A lightweight WordPress plugin that adds an extra math-based security question to the login page.  
Every time someone tries to log in, they must solve a random math question (e.g., `7 + 4 = ?`).  
If the answer is wrong, the login will fail.

---

## ✨ Features
- Random math question (addition only).
- Question changes every time you refresh the login page.
- Prevents login if the answer is incorrect.
- Lightweight and simple – no external libraries.

---

## 📥 Installation
1. Download or clone this repository.
2. Upload the folder to `wp-content/plugins/`.
3. Activate **Admin Math Security** from the WordPress Admin Dashboard.
4. Done! Now your login page will require solving a math question.

---

## 🔒 Security
- Works for all users by default.  
- You can easily modify the code to make it apply **only for Administrator logins**.
